# results/ 归档约定

## 命名

| 类型 | 文件名 | 统计 | 位置 |
|---|---|---|---|
| 正式结果 | `result-YYYYmmdd-HHMMSS.json` | **计入成绩** | `results/`（只留最新一份） |
| 作废结果 | `result-INVALID-<原因>-YYYYmmdd-HHMMSS.json` | **永不计入** | `results/` 原地留档 |
| 历史正式结果 | 原名不变 | 不计入当前成绩 | `results/archive/` |

文件名里带 `-INVALID-` 即作废，任何汇总/对比脚本都要先排除它。

## 什么情况标 INVALID

- **题集不对**：跑的不是 `tasks.json` 里的设计题（例如跑了自己另出的题）——原因写 `自行出题`
- **中途改过判据/工具**：同一轮里评测逻辑和金标不是同一套
- **跑挂了**：异常导致结果不完整

作废不删除：留着能回答「这份成绩为什么不算」。

## 自动归档

`run_eval.py` 每次写出新结果后，会把 `results/` 里更早的正式结果自动移进
`results/archive/`（INVALID 的不动，就留在原地当警示）。所以 `results/` 里
`result-*.json` 只有一份 = 最近一次正式跑。
